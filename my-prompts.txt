 ### Two intentional fixes from the brief

 - Cursor bezier: the brief's formula uses cpX twice, which produces a degenerate quadratic-in-cubic-notation curve,
   not an arc. Implementation uses two distinct control points offset perpendicular to the start→end line so the cursor
   actually arcs upward.
 - Base64 SVG encoding: btoa rejects code points > 255, and Chromium's image decoder rejects data URLs containing UTF-8
   bytes. The placeholder encoder is wrapped in TextEncoder + String.fromCharCode so the data URL is pure ASCII.
